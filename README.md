# Campus Bazaar — Student Marketplace Demo

**Project by:** Sai Sardar Patil  
**Type:** Front-end web development / DevOps-ready project

Campus Bazaar is a responsive, student-focused marketplace demo inspired by local bazaar websites. It showcases product cards, category filters, search, and a simple demo cart. It does not process real payments or orders.

## Tech stack
- HTML5
- CSS3 (responsive layout)
- Vanilla JavaScript
- Git and GitHub
- GitHub Pages for hosting
- GitHub Actions workflow for basic HTML/CSS/JS file validation

## Features
- Responsive design for mobile and desktop
- Product catalogue with sample INR prices
- Category filtering and live search
- Demo cart counter and user feedback
- README and CI workflow included

## Run locally
Open `index.html` in a web browser. No build tools or server are required.

## Publish with GitHub Pages
1. Create a **public** repository named `campus-bazaar`.
2. Upload the contents of this folder to the repository root (including `index.html`).
3. Commit the files.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait for deployment. The URL will be `https://YOUR-USERNAME.github.io/campus-bazaar/`.

Official guide: https://docs.github.com/en/pages/quickstart
